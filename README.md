# 📝 Quote Generator

A responsive web app that delivers random inspirational quotes with a single click.

## 📌 About the Project

**Quote Generator** is a front-end application built using HTML, CSS, and JavaScript. It fetches quotes from a public API and displays them dynamically, offering a smooth user experience and demonstrating DOM manipulation, API integration, and responsive design.

## 🚀 Features

- Fetches random quotes from an external API
- Displays quote and author in a styled container
- Responsive layout using CSS and media queries
- Error handling for failed API calls

## 🛠️ Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Styling and layout
- **JavaScript (ES6)** – Logic and API handling
